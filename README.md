# PE_Compétition_informatique

> **In English:** competitive programming resources: a documented algorithms handbook (data structures, graphs, dynamic programming, number theory, geometry, metaheuristics) and about 45 solved CSES/Codeforces problems, written as Python Jupyter notebooks. The content is in French.

Ressources d'algorithmique pour la programmation compétitive, en Python et sous forme de notebooks Jupyter.

| Fichier | Contenu |
|---|---|
| [`livret_algorithmes.ipynb`](livret_algorithmes.ipynb) | Cours : structures de données, graphes, programmation dynamique, chaînes, théorie des nombres, géométrie, heuristiques. Chaque algorithme est présenté avec son analyse de complexité et une implémentation |
| [`livret_exercices.ipynb`](livret_exercices.ipynb) | Environ 45 problèmes CSES / Codeforces classés par thème, chacun avec deux indications puis une correction détaillée |

## Résultats

- **Prologin :** deux finalistes nationaux, et Centrale Lyon classée 37e des écoles
- **Midnight Code Cup :** problèmes d'optimisation NP-difficiles traités par heuristiques (recuit simulé, recherche locale)
- **Compétition interne :** organisation d'un concours au format SWERC, hébergé sur Codeforces

Réalisé en équipe à l'École Centrale de Lyon (2025-2026). Dépôt d'origine : [Xenow91/PE_Competition_informatique](https://github.com/Xenow91/PE_Competition_informatique)
